# ClusterRSA

**Category:** Cryptography  
**Difficulty:** Medium

A message has been encrypted using RSA, but this time something feels...
more crowded than usual. Can you decrypt it?

The RSA parameters are in `message.txt`.

## Hints

1. RSA usually means two primes... but what if someone got greedy?
2. Prime factors decomposition

## Objective

Recover the hidden flag.

Flag format: `KiST_CS_CTF{...}`

Suggested tools: Python, SageMath, SymPy, FactorDB, or other RSA/factorization tools.
